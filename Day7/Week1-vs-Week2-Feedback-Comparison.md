**Evidence:**

- "Excel crash is really disruptive, losing unsaved work each time." (#13)
- "Excel crashing has become a real productivity problem for finance team." (#20)

**Why it matters:** This has jumped straight to 9 comments in a single week (higher volume than any Week-1 Blocker theme), it causes actual data loss (unsaved work), and it disproportionately affects finance — the same team already impacted by the Week-1 shared drive issue. This should be treated as the new top priority alongside continued monitoring of the Floor 3 printer.
